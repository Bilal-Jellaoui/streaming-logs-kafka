Contrôlable via l'URL requise : /admin/panne?etat=on|off

Bascule Immédiate du Mode Panne
Lorsque le mode panne est actif, tout appel sur /checkout renvoie HTTP 503 et écrit une ligne d'exception dans logs/error.log.

📋 Contrat & Commandes pour les Autres Membres

Utilisez ces requêtes pour tester et intégrer vos modules (JMeter - Membre 2, Kafka Collector - Membre 5, etc.) :

curl -i "http://localhost:8080/checkout"
curl "http://localhost:8080/admin/panne?etat=off"
